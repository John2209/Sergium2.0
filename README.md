# Sergium 1.0

Versão original do simulador Sergium.

Esta branch preserva a implementação monolítica original do projeto, anterior à refatoração e modularização que originaram o Sergium 2.0.

## Estrutura

- `sergium.py` — implementação completa original do simulador;
- `examples/` — programas de exemplo utilizados com esta versão;
- `requirements.txt` — dependências necessárias para execução.

## Histórico

Esta branch é mantida apenas como referência histórica.

O desenvolvimento atual do projeto continua no Sergium 2.0.
